# 🧠 Memory Matching Game

A browser-based **Memory Matching Game** built using **HTML, CSS, and JavaScript**.  
The game challenges players to match pairs of cards while tracking **time** and **moves**, offering multiple difficulty levels and smooth animations.

---

## ✨ Features

- Multiple grid modes: **3×4, 4×4, 4×5, 5×6, 6×6**
- Real-time **timer** and **move counter**
- Smooth **card flip animations** using CSS transforms
- Randomized card shuffling for every game session
- Automatic **match detection** and win condition
- Clean and responsive UI with gradient and blur effects

---

## 🛠️ Tech Stack

- **HTML5** – Game structure and layout  
- **CSS3** – Styling, animations, and responsiveness  
- **JavaScript (ES6)** – Game logic and state management  
- **jQuery** – DOM manipulation and event handling  

---

## 🧩 How the Game Works

1. Cards are shuffled randomly at the start of each game.
2. The player flips two cards per move.
3. If the cards match, they remain flipped.
4. If they don’t match, they flip back automatically.
5. The game ends when all pairs are matched.
6. Final **time taken** and **total moves** are displayed.
